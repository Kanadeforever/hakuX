# hakuX 简体中文自动汉化与发行说明

## 目标

本仓库的 GitHub Actions 每天检查 `rfandango/hakuX` 的 Latest Release。发现尚未发布的正式版本后，获取该 Release 对应的标签源码，应用本仓库的简体中文词条，编译原生核心和 Android APK，并在本仓库的 Releases 中创建正式汉化发行。

不跟踪上游 `master` 的普通提交，不调用翻译 API。

## 文件

- `.github/workflows/upstream-release-zh.yml`：定时检查、构建、签名和发布。
- `localization/strings_zh_cn.json`：首版简体中文词条。
- `tools/localization/apply_translation.py`：把词条应用到 Compose 文案和 Android 字符串资源。
- `tools/localization/prepare_build.py`：调整汉化版包名、版本号和 Gradle 签名配置。

## 如何安装到自己的 Fork

将本补丁包中的文件按原目录结构复制到 `Kanadeforever/hakuX` 仓库根目录，并提交到默认分支。

然后在 GitHub 仓库设置中确认：

1. 打开 `Settings → Actions → General`。
2. 找到 `Workflow permissions`。
3. 选择允许工作流读写仓库内容的选项。
4. 保存设置。
5. 打开 `Actions → hakuX 上游正式版简体中文发行`，手动运行一次工作流。

需要设置四项 Android 签名 Secrets；本补丁另附已生成的签名密钥和配置文本。

## 上游检查规则

- 使用 GitHub API 的 `releases/latest` 查询最新正式 Release。
- 汉化版标签格式为 `zhcn-上游标签`，例如 `zhcn-v1.2.0`。
- 如果该标签已有发行记录，则跳过。
- 只有汉化处理、原生编译、APK 打包和 APK ZIP 完整性检查全部成功，才创建 Release。
- 失败时不会创建新 Release，下一次每日检查仍可重试。

## 汉化策略

首版词条采用精确匹配，不会把任意英文变量、文件路径、日志、游戏内容或网络协议字段直接替换成中文。

脚本会：

- 将匹配到的 Compose `Text("...")` 静态文字改为 Android 字符串资源调用。
- 处理匹配到的 `contentDescription` 静态文案。
- 对上游已有的 `strings.xml` 做精确文字匹配。
- 生成 `values-zh-rCN/strings.xml`。
- 注册 `zh-CN` 应用语言。
- 生成 `translation-audit.txt`，记录已命中和未命中的词条。

首版是部分汉化。未匹配的词条可能是上游实际没有使用的标签，也可能是界面中使用了其他写法的英文。需要根据审查报告继续补译。若没有任何界面文字命中，工作流会停止，不会发布纯英文 APK。

## APK 包名和版本号

汉化版应用包名在上游包名后追加 `.zhcn`，以便与官方版并行安装。版本号根据上游三段式标签计算，避免不同上游发行版本出现相同或倒退的 Android `versionCode`。

## 签名方案与限制

APK 使用维护者生成并长期保管的固定社区签名密钥。工作流从 GitHub Actions Secrets 读取密钥库和密码，不在公开源码仓库中保存私钥，也不依赖 Actions 缓存保存签名。

需要在仓库 `Settings → Secrets and variables → Actions` 中配置以下四项：

- `ANDROID_KEYSTORE_BASE64`：签名密钥库文件的单行 Base64 内容。
- `ANDROID_KEYSTORE_PASSWORD`：密钥库密码。
- `ANDROID_KEY_ALIAS`：密钥别名。
- `ANDROID_KEY_PASSWORD`：私钥密码。

不要把 `.jks` 文件、Base64 密钥内容或密码提交到公开仓库。若更换签名密钥，已安装旧签名版本的用户通常需要先卸载旧版才能安装新版。固定保存原密钥可以维持连续升级能力。

## 构建环境

工作流依据上游 Android 构建说明配置：

- JDK 21
- Android SDK 36
- Build Tools 36.1.0
- NDK 29.0.14206865
- CMake 3.30.3
- Ninja
- 上游 `android/README.md` 中固定版本的原生依赖
- 上游 FEX 子模块及其嵌套子模块

每个成功发行都会附带 APK、源码快照、构建信息、SHA-256 校验值和翻译审查报告。

## 已知限制

- 词条需要逐步根据实际上游 UI 补全。
- 自动化仅对标准静态 Compose 文案做精确替换；动态拼接文本、自定义绘制文字、原生 C/C++ 文案和部分非 Compose 控件需要单独处理。
- 本补丁尚未在 GitHub 云端执行过完整构建。首次运行必须以 Actions 实际结果为准；如果上游构建说明或源码结构变化，工作流会在相应检查步骤停止。
